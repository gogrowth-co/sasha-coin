## What it is
Global online buildathon to onboard Web3/AI developers to Casper. Build production-ready apps at the
convergence of **Agentic AI + DeFi + Real-World Assets (RWA)** on Casper Network. One unified
**"Casper Innovation Track."** Two-phase: Qualification Round (community voting + prototype qualification)
→ Final Round (professional jury).

## Submission requirements (all 3 mandatory)
1. **Working prototype on Casper Testnet** with a **transaction-producing on-chain component**
2. **Open-source GitHub repo** with README (docs + usage)
3. **Demo video** (public, walkthrough of features)

## Advancement mechanism (Qualification Round)
- **Community Voting Path:** top 3 projects by votes on **CSPR.fans app** → finals, no extra judging.
- **Builder Merit Path:** all others must meet technical eligibility (working Testnet prototype w/ on-chain tx) to advance to jury evaluation.

## Eligibility
- Any team size / solo.
- All code + content **original and newly developed for the Buildathon** (cannot submit pre-existing work).
- Focus: Agentic AI apps, emphasis on DeFi and/or RWA on Casper.

## Final Round judging criteria
Technical Execution · Innovation & Originality · Use of AI / Agentic Systems · Real-World Applicability
(DeFi & RWA) · UX & Design · Working Smart Contracts (deployed on Testnet) · Long-Term Launch Plans
(real project, socials in place, deployment plans) · Potential for Long-Term Impact.

## Tech stack to build on (Casper AI Toolkit — casper.network/ai)
- **x402 Micropayments** — HTTP-native pay-per-API-request w/ cryptographic proof (agents call paid
  endpoint → HTTP 402 + price → sign authorization → data back). $100K of the prize is x402 credits;
  participating teams get **sponsored x402 Facilitator usage** (free on-chain tx for dev/test).
- **MCP Servers** — Casper MCP Server (query balances, submit deploys, read contract state) + CSPR.trade
  MCP (DEX swaps, LP, portfolio).
- **CSPR.click AI Agent Skill** — wallet creation, tx signing, CSPR.cloud API proxy, contract deploy.
- **CSPR.cloud APIs** — REST / Streaming / Node middleware.
- **Odra Framework** — Rust-based smart contract framework, llms.txt support (AI can read docs + generate
  Casper contracts autonomously). Casper is the first WebAssembly-native L1.
- "Casper Manifest" = strategic vision (Casper as trust layer for the agent economy).
