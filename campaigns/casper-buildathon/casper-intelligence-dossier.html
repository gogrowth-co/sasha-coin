07 / DOCS & DEVELOPER PATH

From zero to one Testnet tx.

The fastest legitimate route (Odra livenet)
  • cargo odra new — scaffold a Rust contract.
  • Get a Testnet key + faucet at testnet.cspr.live/tools/faucet (PEM key).
  • Set 3 env vars: secret-key path · node address · CHAIN_NAME=casper-test.
  • cargo run --features livenet → prints a tx hash + testnet.cspr.live link. That is the submission requirement.
  • Layer the agentic story with x402 (agent signs a CEP-18 payment, settles on casper-test).
Verdict: "one agentic Testnet tx" is reachable in a single session. Odra's llms.txt lets an AI self-serve the whole flow.
