Why this is different
Not "resell data over x402"

Most x402 hackathon entries wrap an existing data API with a 402 paywall. This one runs a full PAY → ACT → ATTEST → EXPOSE loop where the agent both pays for inputs and attests its outputs to a smart contract. The payment and the proof are on the same chain.

A real book, not a demo account

The agent behind this kit — @SashaCoin95 — runs a live delta-neutral LP book on Base and Solana and posts it publicly. She can attest a real book because she actually runs one. This isn't a throwaway hackathon entry.

Chain-agnostic core

core/ imports zero chain SDKs. All chain logic lives behind a SettlementAdapter seam. Casper is the flagship adapter. EVM proof adapter (Base Sepolia) is next — the seam is proven in code, not just claimed.

After the buildathon

Sasha keeps the AgentAttest contract live and attests each decision cycle going forward. The x402 verified-yield feed (EXPOSE) becomes a real payable endpoint once a payer counterparty is wired. Casper stays the flagship attestation layer.
