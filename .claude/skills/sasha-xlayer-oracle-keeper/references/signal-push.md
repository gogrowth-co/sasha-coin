# Signal push — push-signal-to-xlayer.js

Pushes Sasha's fused risk signal to `SashaOracle.setFee()` on X Layer.

## Input
Reads `content/mantle-signal.json` (produced by `sasha-signal-fusion`). The signal carries the risk level the oracle should store.

## Invocation
```
node scripts/push-signal-to-xlayer.js               # push if risk changed
node scripts/push-signal-to-xlayer.js --force        # re-push even if unchanged (liveness)
node scripts/push-signal-to-xlayer.js --heartbeat    # push only if risk changed OR updatedAt >= 5h old
node scripts/push-signal-to-xlayer.js --dry-run      # preview (now checks live chain state too — safe to test --heartbeat)
```

## Cron (VPS)
`/etc/cron.d/sasha-oracle` runs `--heartbeat` every 4h (fixed 2026-07-05, audit M-1). The old `--force` every 2h refreshed `updatedAt` regardless of whether anything changed, which defeated the oracle's own 6h staleness fallback — the whole point of that fallback is to let the oracle honestly go stale if the pipeline dies, not to be permanently masked. Heartbeat mode pushes only when risk changed or `updatedAt` is nearing the 6h cutoff (>= 5h old), cutting real pushes from 12/day to ~1-4/day. A signal-age guard also refuses to push `content/mantle-signal.json` if it's older than 6h — a stale signal is never pushed as fresh.

**Known state (2026-07-05):** `mantle-signal.json` is only regenerated by `auto-trade.js` (via `sasha-trade` cron), which was disabled the same day (DEC-013, Mantle/Solana trader hibernation). With no producer left, the signal will age past 6h and the guard will block pushes going forward — the oracle is expected to go stale honestly rather than being kept alive artificially. See `docs/decision-log.md` DEC-014.

## Output / verification
On success, logs `{txHash, fee, riskLevel, pushedAt, explorer}`. Verify on `https://www.oklink.com/x-layer/tx/<txHash>`.

## Failure modes
- **Gas too low** → estimate runs low on X Layer; apply 50% buffer on `gasLimit`.
- **`CurrencyNotSettled`** → decode the revert and re-quote; do not blind-retry.
- **spawnSync ETIMEDOUT** (if shelling out under box load) → not an X Layer error; see `sasha-ops-hardening`.
- **Empty 0.3% pool** → route via the 0.01% pool.
