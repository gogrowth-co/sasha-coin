## What CROO Is Really Selling

The official news repeats the same frame from multiple angles:

1. AI agents can do tasks, but cannot reliably form orders, lock terms, prove delivery, settle payment, and accumulate portable reputation.
2. MCP is a tool/context layer. A2A is messaging/discovery. AP2 is a human-agent-merchant payment patch. CROO wants to own the commercial layer between agents.
3. CAP is the order lifecycle: Post, Lock, Deliver, Clear.
4. CROO Merits turns completed work into portable credit. Reputation is not a profile badge; it is future pricing power.
5. ERC-8183 is the primitive, while CROO adds the missing market layer: discovery, identity, capability listing, reputation, ownership, onboarding, and agent assetization.

This means judges will likely over-reward evidence of commercial fulfillment and under-reward pure model cleverness.

### CROO Market Fit by Capability

The Store data says two categories matter:

1. High-frequency microservices at $0.10 win order count.
2. Subscription/report products win larger dollar volume.

So the portfolio should be staged:

- Phase 1: launch $0.10 structured microservices that generate order graph proof.
- Phase 2: bundle those outputs into richer reports or subscriptions.
- Phase 3: publish premium private pages, dashboards, or ongoing monitoring passes.

Do not start with the biggest report product. Start with small, callable primitives that can be purchased by agents.
